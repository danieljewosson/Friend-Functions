# C++ Friend Function — Point

A small educational C++ project demonstrating how to use a `friend function` to access and modify private members of a class.

# About the Project

This project contains a simple `Point` class that stores two coordinates: `x` and `y`.

The coordinates are declared as `private`, which means they cannot be accessed directly from outside the class.

The `ChangeValue()` function is declared as a friend function, allowing it to access and modify the private members of the Point class.
